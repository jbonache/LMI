    3.2 Enviament amb GET

    Mètodes d'enviaments dels formularis HTML

    Els formularis HTML permeten enviar informació des del navegador fins al servidor.
    Per fer-ho, s’utilitzen principalment dos mètodes: GET i POST.

    Cada mètode determina com es transmeten les dades i quan és millor utilitzar-lo.

    Mètode d'enviament GET

    El mètode GET envia les dades del formulari afegint-les a la URL com a paràmetres de consulta (query string).

    Com funciona?

    Quan envies un formulari amb method="get", el navegador crea una URL com aquesta: resultat.html?nom=Joan&sexe=Home&email=joan@gmail.com

    • El nom del fitxer o pàgina (ex: resultat.html) indica on s’envien les dades.
    • Després del signe de pregunta ?, hi ha una llista de parelles clau=valor separades per &.

    Característiques principals

    • Les dades són visibles a la barra d’adreces del navegador.
    • L’URL es pot compartir o desar (conté els valors).
    • Es pot emmagatzemar a la memòria cau o guardar a l’historial.
    • No és segur per a informació sensible (com contrasenyes).
    • Té limitacions de mida (la URL no pot ser massa llarga).
    • Ideal per a cerques, filtres o consultes simples.

    Exemple de formulari GET

    <form action="resultat_get.html" method="get">
    <label for="nom">Nom:</label><br>
    <input type="text" id="nom" name="nom" required><br><br>
        Sexe:<br>
    <input type="radio" id="home" name="sexe" value="Home" required>
    <label for="home">Home</label><br>
    <input type="radio" id="dona" name="sexe" value="Dona">
    <label for="dona">Dona</label><br><br>
    <label for="email">Correu electrònic:</label><br>
    <input type="email" id="email" name="email" required><br><br>
    <label for="password">Contrasenya:</label><br>
    <input type="password" id="password" name="password" required><br><br>
    <input type="submit" value="Enviar dades">
</form>
    Quan s’envia, la pàgina pot obrir en:
    resultat_get.html?nom=Joan&sexe=Home&email=joan@gmail.com&password=1234

    ✅ Quan utilitzar GET?

    • Formularis de cerca o consulta.
    • Quan vols compartir o guardar l’enllaç amb els resultats.
    • Quan les dades no són confidencials.
