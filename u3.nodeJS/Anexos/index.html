    Funció prompt()

    La funció prompt() s’utilitza per a demanar dades a l’usuari mitjançant una finestra emergent del navegador.

    És una eina molt habitual en programació estructurada, ja que permet treballar la lògica del programa sense utilitzar el DOM.

    Sintaxi bàsica

    prompt(missatge);

    Exemple:

    let nom = prompt("Com et dius?");

    Sintaxi amb valor per defecte

    let ciutat = prompt("En quina ciutat vius?", "València");

    Si l’usuari no escriu res i accepta, el valor serà "València"

    Valor retornat per prompt()

    La funció prompt() sempre retorna un string, independentment del que introduïsca l’usuari.

    let numero = prompt("Introdueix un número");

    Encara que l’usuari escriga 5, el valor guardat serà:

    "5"

    Conversió de tipus

    Com que prompt() retorna un string, sovint es combina amb funcions de conversió:

    let edat = parseInt(prompt("Introdueix la teua edat:"));
let preu = parseFloat(prompt("Introdueix el preu:"));
    Cas especial: botó Cancel·lar

    Si l’usuari prem el botó Cancel·lar, la funció retorna null.

    resposta === null

    Funció alert()

    La funció alert() s’utilitza per a mostrar informació a l’usuari mitjançant una finestra emergent del navegador. És molt útil per a debugejar i per a practicar programació estructurada sense utilitzar el DOM.

    Sintaxi

    alert(missatge);

    Exemples bàsics

    Mostrar un text simple:

    alert("Benvingut al programa!");

    Mostrar una variable:

    let resultat = 42;
alert("El resultat és: " + resultat);

    Mostrar una operació: 

    let a = 5;
let b = 3;
alert("La suma de a + b és: " + (a + b));

    Ús combinat amb prompt()

    És habitual usar alert() per a mostrar els resultats després de demanar dades amb prompt(): 

    let nom = prompt("Com et dius?");
alert("Hola " + nom + "! Benvingut al programa.");


    let numero = parseInt(prompt("Introdueix un número:"));
alert("Has introduït el número: " + numero);

    Funcions principals de la llibreria Math

    La llibreria Math permet realitzar operacions matemàtiques bàsiques i avançades sense necessitat d’importar cap mòdul. Està inclosa per defecte en JavaScript.

    Funcions principals

    • Math.random()
      Genera un número decimal aleatori entre 0 (inclòs) i 1 (exclòs).

    • Math.floor(x)
      Arrodoneix el número x cap avall al nombre enter més proper.

    • Math.ceil(x)
      Arrodoneix el número x cap amunt al nombre enter més proper.

    • Math.round(x)
      Arrodoneix el número x al nombre enter més proper segons decimals.

    • Math.max(a, b, ...)
      Retorna el valor màxim d’un conjunt de números.

    • Math.min(a, b, ...)
      Retorna el valor mínim d’un conjunt de números.

    • Math.abs(x)
      Retorna el valor absolut de x.

    • Math.pow(x, y)
      Retorna x elevat a la potència y.

    • Math.sqrt(x)
      Retorna l’arrel quadrada de x.

    • Math.PI
      Retorna el valor de π.

    • Math.sin(x), Math.cos(x), Math.tan(x)
      Funcions trigonomètriques; x en radians.
