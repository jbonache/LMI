    Objecte Number en JavaScript

    Number és l’objecte natiu de JavaScript que representa valors numèrics, tant enters com decimals.

    Encara que existeix el constructor Number, habitualment s’utilitzen valors literals, ja que JavaScript encapsula automàticament els nombres com a objectes quan és necessari.

    Mètodes estàtics més utilitzats

    • Number.isNaN(valor) : Comprova si un valor és NaN.

    • Number.isInteger(valor) : Indica si un valor és un nombre enter.

    • Number.parseInt(text) : Converteix una cadena a un nombre enter.

    • Number.parseFloat(text) : Converteix una cadena a un nombre decimal.

    Exemples

    1) Situació habitual: llegir una quantitat introduïda com a text (per exemple, des d’un formulari o un prompt) i convertir-la a nombre enter. parseInt llig el text fins que troba un caràcter que no és numèric: 

    let edatText = "18 anys";
let edat = Number.parseInt(edatText);   // edat val 18

    2) Diferència pràctica entre parseInt i parseFloat: 

    Number.parseInt("3.75");    // 3
Number.parseFloat("3.75"); // 3.75

    3) A tindre en compte: 

    Number.parseInt("abc");   // NaN
Number.parseFloat("abc"); // NaN

    Mètodes d’instància més utilitzats

    • toFixed(decimals) : Retorna una representació del nombre amb un nombre fix de decimals. 

      let n = 4.5678;
n.toFixed(2);  // 4.56

    • toString() : Converteix el nombre a una cadena de text. 

      let valor = 50;
valor.toString();  // "50"

    • valueOf() : Retorna el valor primitiu del nombre. 

      let num = 20;
num.valueOf();  //20

    Objecte String en JavaScript

    String és l’objecte que representa cadenes de text en JavaScript. Tot text literal, com "Hola món", és un String.

    Encara que existeix el constructor new String(), en la pràctica sempre s’utilitzen literals de text.

    Mètodes més utilitzats

    • Transformació de text

      • toUpperCase() → converteix tot el text a majúscules
      • toLowerCase() → converteix tot el text a minúscules
      • trim() → elimina espais inicials i finals
      • trimStart() → elimina espais inicials
      • trimEnd() → elimina espais finals

    • Accés i manipulació

      • charAt(index) → retorna el caràcter en la posició indicada
      • charCodeAt(index) → retorna el codi Unicode del caràcter
      • length → longitud del text
      • substring(inici, fi) → retorna una subcadena
      • concat() → concatena cadenes
      • split(separador) → converteix el text en un array segons el separador
      • includes(text) → comprova si conté un text concret
      • startsWith(text) → comprova si comença amb un text
      • endsWith(text) → comprova si acaba amb un text
      • replace(textAntic, textNou) → substitueix parts del text

    • Conversió

      • toString() → converteix a text (per si és objecte)

    Objecte Date en JavaScript

    Date és l’objecte natiu que permet treballar amb dates i hores en JavaScript. Permet obtenir, manipular i calcular amb anys, mesos, dies, hores, minuts, segons i mil·lisegons.

    • Es crea amb el constructor new Date().
    • Si no es passa cap paràmetre, retorna la data i hora actuals.
    • Les dates internament es guarden com a mil·lisegons des del 1 de gener de 1970 (Unix Epoch).

    Creació de dates

    • new Date() → data i hora actuals
    • new Date(any, mes, dia, hores, minuts, segons, ms) → data específica
    • new Date("YYYY-MM-DD") → data a partir d’una cadena
    • new Date(ms) → data a partir de mil·lisegons des del 1970
    // Data i hora actual
let ara = new Date();

// Data concreta per any, mes, dia
let data1 = new Date(2026, 1, 4); // 4 de febrer 2026 (mes 1 = febrer)

// Data a partir de cadena ISO
let data2 = new Date("2026-02-04T12:30:00");

    Mètodes més utilitzats

    • Obtenir parts de la data

      • getFullYear() → any complet (ex. 2026)
      • getMonth() → mes (0–11, 0=gener)
      • getDate() → dia del mes (1–31)
      • getDay() → dia de la setmana (0=diumenge)
      • getHours() → hores (0–23)
      • getMinutes() → minuts (0–59)
      • getSeconds() → segons (0–59)
      • getMilliseconds() → mil·lisegons (0–999)
    let d = new Date("2026-02-04T12:34:56");

d.getFullYear();   // 2026
d.getMonth();      // 2 (febrer)
d.getDate();       // 4
d.getDay();        // 3 (dimecres)
d.getHours();      // 12
d.getMinutes();    // 34
d.getSeconds();    // 56
d.getMilliseconds(); // 0
d.getTime();       // mil·lisegons des del 1970

    • Modificar parts de la data

      • setFullYear(any) → canvia l’any
      • setMonth(mes) → canvia el mes (0–11)
      • setDate(dia) → canvia el dia del mes
      • setHours(hores) → canvia les hores
      • setMinutes(minuts) → canvia els minuts
      • setSeconds(segons) → canvia els segons
      • setMilliseconds(ms) → canvia els mil·lisegons
      • setTime(ms) → defineix la data a partir de mil·lisegons des del 1970
    let d = new Date("2026-02-04T12:34:56");

d.setFullYear(2027);
d.setMonth(5);       // juny
d.setDate(15);
d.setHours(18);
d.setMinutes(45);
d.setSeconds(30);
d.setMilliseconds(500);
d.setTime(1675500000000); // defineix data des de mil·lisegons

    • Representació de la data

    • toString() → retorna la data completa en format text local

    • toDateString() → només data
    • toTimeString() → només hora
    • toISOString() → format ISO 8601 (ex. "2026-02-04T12:34:56.789Z")
    • toLocaleDateString() → format data segons local
    • toLocaleTimeString() → format hora segons local
    let d = new Date("2026-02-04T12:34:56");

d.toString();            // "Wed Feb 04 2026 12:34:56 GMT+0100 (CET)"
d.toDateString();        // "Wed Feb 04 2026"
d.toTimeString();        // "12:34:56 GMT+0100 (CET)"
d.toISOString();          // "2026-02-04T11:34:56.000Z"
d.toLocaleDateString();  // "4/2/2026" (format segons local)
d.toLocaleTimeString();  // "12:34:56" (format segons local)

    Objecte Array en JavaScript

    Array és l’objecte natiu que representa col·leccions ordenades de valors en JavaScript. Característiques:

    • Els elements de l'array poden ser de qualsevol tipus: nombres, cadenes, objectes, altres arrays… i es poden barrejar.
    • IMPORTANT: l’índex comença en 0.
    • Es pot crear amb literals [] o amb el constructor new Array().

    Creació d’Arrays

    // Literal
let nums = [1, 2, 3, 4, 5];
let noms = ["Anna", "Joan", "Laura"];
let mix = [1, true, "Marc", {"id": 1, "producte" : llet, "preu" : 1.27}]

// Constructor
let arrayBuit = new Array();
let arrayTamaño5 = new Array(5); // array amb 5 posicions buides

    Mètodes més utilitzats

    • Afegir i eliminar elements

      • push(valor) → afegeix un element al final de l’array
      • pop() → elimina l’últim element de l’array
      • shift() → elimina el primer element de l’array
      • unshift(valor) → afegeix un element al principi de l’array
      • slice(inici, fi) → retorna una còpia d’una sub-secció de l’array des d'inici a fi, sense incloure a aques (fi - 1). Si no es posa inici, sols un parametre, es retorna la sub-secció a partir del valor indicat.

      • splice(index, count, elements...) → elimina i/o afegeix elements en qualsevol posició de l’array. index: indica des d'on s'inicia a borrar/afegir count: valors a borrar/afegir des d'inici. 0 indica cap elements: valor a afegir

      • sort() → ordena els elements de l’array

      • reverse() → inverteix l’ordre dels elements
    // push → afegir al final
nums.push(6);       // [1,2,3,4,5,6]

// pop → eliminar l’últim element
nums.pop();         // [1,2,3,4,5]

// unshift → afegir al principi
noms.unshift("Pau"); // ["Pau","Anna","Joan","Laura"]

// shift → eliminar el primer element
noms.shift();        // ["Anna","Joan","Laura"]

// Retornar una còpia d'una secció de l'array
//let nums = [10, 20, 30, 40, 50];
let array = nums.slice(2); // array = [30, 40, 50]
let array = nums.slice(1,4); // array = [20, 30, 40]

// Eliminar elements a partir d'una posició 
// nums = [10, 20, 30, 40, 50];
nums.splice(1, 2);  // nums → [10, 40, 50]

    • Accés i informació

      • length → retorna la longitud de l’array
      • indexOf(valor) → retorna la posició d’un element, o -1 si no existeix
      • includes(valor) → retorna true si l’element existeix, false en cas contrari
    nums.length;           // 5
noms.indexOf("Joan");  // 1
noms.includes("Marc"); // false
