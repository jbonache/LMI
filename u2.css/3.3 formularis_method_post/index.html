    3.3 Enviament amb POST

    Mètode d'enviament POST

    El mètode POST és un dels dos principals mètodes que utilitzen els formularis HTML per enviar dades des del navegador cap al servidor.
    A diferència del mètode GET, amb POST les dades no viatgen a la URL, sinó que s’envien de manera interna (al cos de la petició HTTP).

    Com funciona?

    Quan un usuari omple un formulari i el envia amb method="post", el navegador:

    1. Envia una petició HTTP POST al servidor.
    2. Les dades del formulari s’inclouen dins del cos (body) de la petició, no a la URL.
    3. El servidor rep aquestes dades i pot processar-les, guardar-les o validar-les.

    Exemple simplificat del que veu el servidor:

    POST /resultat.php HTTP/1.1
Host: exemple.com
Content-Type: application/x-www-form-urlencoded
nom=Joan&email=joan@gmail.com

    Característiques principals

    • Les dades no apareixen a la URL → més privades i segures.
    • Permet enviar grans quantitats d’informació (sense límit pràctic).
    • No es pot desar o compartir l’URL amb els valors enviats.
    • No queda registrada a l’historial del navegador.
    • Ideal per a formularis que modifiquen o creen dades (registre, login, compres, etc.).

    Exemple bàsic de formulari POST

    <form action="resultat_post.php" method="post">
  <label for="nom">Nom:</label>
  <input type="text" id="nom" name="nom" required>
  <label>Sexe:</label>
  <input type="radio" id="home" name="sexe" value="Home" required> Home<br>
  <input type="radio" id="dona" name="sexe" value="Dona"> Dona<br>
  <label for="email">Correu electrònic:</label>
  <input type="email" id="email" name="email" required>
  <label for="password">Contrasenya:</label>
  <input type="password" id="password" name="password" required>
  <input type="submit" value="Enviar">
</form>

    ✅ Quan utilitzar POST

    • Quan vols enviar informació confidencial o privada.
    • Quan el formulari crea o modifica dades al servidor (registre, compra, edició, etc.).
    • Quan cal enviar molta informació o fitxers adjunts (enctype="multipart/form-data").
