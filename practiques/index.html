    1. Pràctica1: HTML i CSS

    🧩 Pràctica: Creació d'una pàgina web corporativa amb estil propi

    🧱 Descripció general

    Has de dissenyar una pàgina web informativa per a una empresa real o inventada. Aquesta web ha de transmetre una imatge clara i coherent de l'empresa i estar formada per diverses seccions organitzades de manera lògica.

    Cada alumne/a triarà el nom, el sector, el contingut i l'estètica del seu projecte.

    Dinàmica de treball

    • La pàgina web anirà fent-se a tandes d'exercicis.

    • En acabar un grup d’exercicis, hauràs de fer l’entrega corresponent a eixos exercicis.

    • Aquestes entregues s’avaluaran com a pràctiques.

    Exercici 1. 🗂️ Estructura de directoris

    En aquest exercici anem a crear l’estructura bàsica de directoris (carpetes) de les teues pàgines web.

    1. Ves a la teua carpeta Documents i crea una carpeta anomenada public_html.
    2. Dins d’aquesta, crea una carpeta on anirà la teua pàgina web, anomenada empresa.
    3. I dins d’aquesta, crea tres carpetes més:
      • img
      • css
      • fonts

    Crea també, dins de public_html, una carpeta anomenada proves, per a guardar les pàgines que no siguen de la web de la teua empresa.

    Exercici 2. Plantilla

    En aquesta pràctica crearàs la plantilla bàsica de la teua primera pàgina web.

    1. Crea una pàgina sense contingut amb les metadades següents:
    2. Codificació: UTF-8
    3. Autor: author: el teu nom
    4. Descripció: description: "nom de l’empresa."
    5. Paraules clau: keywords: "paraules relacionades amb els articles de la teua empresa, separades amb comes"

    6. Viewport

    7. Comprova que la codificació de la pàgina és UTF-8 (en propietats del document).

    8. Guarda la plantilla amb el nom plantilla_empresa.html dins de la carpeta proves.

    9. Torna-la a guardar amb el nom index.html dins de la carpeta empresa.

    10. Edita la pàgina index.html i escriu un text de prova dins de l’etiqueta <body> de la pàgina.

    11. Guarda-la i comprova que es visualitza correctament al navegador.

    Exercici 3. 📝 Text

    A partir de l’arxiu index.html de la pràctica anterior, heu de crear el contingut d’una pàgina que mostre informació sobre la vostra empresa.

    La pàgina ha de tindre, com a mínim, les seccions següents:

    • Informació de l’empresa: nom, adreça, sector, etc.
    • Descripció de l’empresa: breu història, característiques, etc.
    • Productes: una breu descripció dels productes que comercialitza o de les activitats que realitza.

    Elements HTML que ha de contindre la pàgina

    1. Un títol (<title>) amb el nom de l’empresa.
    2. Informació sobre la pàgina amb les etiquetes vistes fins ara.
    3. Títols necessaris (atenció a l’ordre de niuament i a l’estructura del document).
    4. Paràgrafs per al text.
    5. Elements d’èmfasi: <em> i <strong>.
    6. Elements semàntics utilitzats correctament, com a mínim:
      • <header>
      • <main>
      • <footer>
      • (Opcionalment també <section>, <article>, etc.)
    7. Altres elements que considereu necessaris.

    📦 1a Entrega

    Comprimeix la carpeta public_html en format ZIP i entrega-la a Aules amb el nom entrega1.zip

    Exercici 4. 🎨 Propietats de text

    Crea un full d’estil extern anomenat general.css per a la teua pàgina.
    Guarda’l dins de la carpeta css i enllaça’l a totes les pàgines de la teua web.

    Defineix les següents propietats d’estils:

    body

    • font-family: utilitza una família sans serif.

    Títols (h1, h2, …)

    • font-family: utilitza una família serif o sans serif.
      Opcionalment, pots utilitzar una font externa guardada en la carpeta fonts, o una font de Google.
    • font-size: utilitza diversos valors en em.
    • font-style: prova diversos valors com normal, italic o oblique, segons el nivell de la capçalera.
    • font-weight: prova diversos valors segons el nivell de la capçalera.

    p

    • font-family: utilitza una família serif.
    • font-size: utilitza valors en %.

    Exercici 5. 🎨🎨 Més propietats de text

    Modifica el full d’estil general.css per a afegir les següents propietats d’estils:

    Títols (h1, h2, …)

    • text-align
    • text-decoration
    • text-shadow (opcional)
    • text-transform (opcional)

    p

    • text-align
    • line-height (opcional)
    • text-indent (opcional)

    Exercici 6. 🖌️ Colors

    Modifica el full d’estil general.css per a afegir les propietats de color de text i color de fons als següents elements:

    • body: text i fons.
    • Capçaleres (h1, h2, …): text i fons.
    • p: només text.

    Utilitza les tres formes de codificar els colors: 1. Noms de color (red, blue, green, etc.). 2. Valors RGB (rgb(255, 0, 0)). 3. Valors hexadecimals (#FF0000).

    Per a triar la combinació de colors pots utilitzar Adobe Color o W3Schools Color Picker.

    📦 2a Entrega

    Comprimeix la carpeta public_html en format ZIP i entrega-la a Aules amb el nom entrega2.zip

    Exercici 7. 🔗 Enllaços externs

    Crea una nova pàgina anomenada enlaces.html i afegeix 3 enllaços externs relacionats amb els articles de la teua empresa.
    Utilitza també les etiquetes <hx>, <p>, etc. necessàries.
    Crea també un enllaç relatiu a la pàgina index.html.

    En la teua pàgina index.html crea un enllaç intern relatiu a la pàgina enlaces.html que acabes de crear.

    Els enllaços interns entre les teues pàgines han d’estar dins de l’etiqueta <nav>.

    Exercici 8. 🔗🔗 Enllaços locals

    Crea una nova pàgina anomenada contacte.html i afegeix la informació de contacte de la teua empresa: - Adreça postal completa - Telèfon (inventat) - Correu electrònic (enllaç de correu electrònic)

    Utilitza també les etiquetes <hx>, <p>, etc. necessàries.
    Crea enllaços relatius a la resta de pàgines del teu lloc web.

    En la resta de pàgines, crea enllaços relatius a la pàgina contacte.html.
    Tots aquests enllaços interns han d’estar dins de l’etiqueta <nav>.

    En general.css, crea els estils per als enllaços (colors i text-decoration) i prova diversos valors per a: - a:link - a:visited - a:hover - a:active

    🗺️ Opcionalment, insereix un mapa de Google Maps amb la direcció de la teua empresa.

    Exercici 9. 📄 Llistes

    Crea una pàgina anomenada productes.html.
    En aquesta pàgina crea llistes amb les categories de productes de la teua empresa, amb alguns dels productes més destacats.
    Utilitza llistes numerades i sense numerar, o una combinació d’ambdues.

    Opcionalment, utilitza llistes de definició.

    Crea estils per a les teues llistes: canvia els marcadors i, opcionalment, utilitza imatges com a marcadors.

    Afegeix enllaços relatius a la resta de pàgines dins de l’etiqueta <nav>.

    Afegeix també els enllaços necessaris perquè la nova pàgina siga accessible des de les barres de navegació de totes les pàgines del teu lloc web.

    Exercici 10. 🖼️ Imatges

    Modifica la pàgina productes.html per a afegir almenys 3 imatges dels productes llistats.
    Insereix també una o diverses imatges a la pàgina index.html.

    Totes les imatges han de tindre text alternatiu (alt) amb la descripció del seu contingut i han d’estar guardades dins de la carpeta img (empresa/img).

    Modifica les imatges amb el GIMP per tal que la seua mida s’ajuste a la pàgina.
    Estableix també l’ample i alt amb l’atribut style.

    Fes altres modificacions amb CSS al teu gust: - Centrar imatges
    - Vores arrodonides
    - Imatges responsives

    Exercici 11. 🖼️ Imatges de fons

    Modifica el full d’estil general.css per a afegir imatges de fons, utilitzant les propietats background.

    📦 3a Entrega

    Comprimeix la carpeta public_html en format ZIP i entrega-la a Aules amb el nom entrega3.zip

    Exercici 12. Classes

    Crea una classe anomenada destacat i aplica-la a un paràgraf de la teua pàgina index.html.
    Defineix regles per al tipus de lletra, color, ressaltat, etc., de manera que el paràgraf es diferencie de la resta.
    Opcionalment, aplica-la a altres paràgrafs de la teua web.

    Exercici 13. <span>

    Dins d’un altre paràgraf de la pàgina index.html, posa una frase dins d’una etiqueta <span> i aplica-li la classe destacat.
    En el full d’estil CSS, crea un estil nou que només s’aplique als span.destacat que estiguen dins de paràgrafs, diferent de l’estil de l’exercici anterior.

    Exercici 14. Id’s i estils de llistes

    Crea un id anomenat main-nav i aplica’l a l’etiqueta <nav> de totes les pàgines que tinguen enllaços de navegació interns.
    Fica els enllaços com a elements d’una llista no ordenada i crea els estils CSS perquè es visualitze en forma de menú horitzontal.

    Exercici 15. 🎵 🎥 Multimèdia

    Crea, dins del directori arrel de la teua web, una carpeta anomenada media.
    Crea una pàgina anomenada multimedia.html dins del directori principal.

    En aquesta pàgina has d’inserir:

    • Un arxiu de vídeo (amb mida reduïda)
    • Un arxiu d’àudio
    • Un vídeo de YouTube

    Guarda els dos primers arxius dins de la carpeta media.

    Afegeix els enllaços necessaris perquè la nova pàgina siga accessible des de les barres de navegació de totes les pàgines.
    Tots aquests enllaços han d’estar dins de l’etiqueta <nav>.

    Exercici 16. Creació de taules

    Crea una pàgina anomenada horari.html dins de la teua carpeta personal.
    En aquesta pàgina, crea una taula amb l’horari de l’empresa.

    • Utilitza <thead> i <th> per a la primera fila (dies de la setmana).
    • Utilitza <tbody> per a la resta.
    • Fes servir els atributs colspan i rowspan per agrupar hores.

    Afegeix enllaços relatius dins de <nav> perquè siga accessible des de totes les pàgines.

    Maqueta amb CSS la taula utilitzant: - border, border-collapse - text-align, vertical-align - Colors de fons i text - Amplària (width) i altura (height) per a la taula i els seus elements

    📦 4a Entrega

    Comprimeix la carpeta public_html en format ZIP i entrega-la a Aules amb el nom entrega4.zip

    Exercici 17. Formularis I

    Modifica la pàgina contacte.html per a afegir un formulari de contacte amb els següents elements:

    • Nom: input type="text"
    • Correu electrònic: input type="email"
    • Missatge: <textarea>
    • Botó enviar: input type="submit"

    Utilitza <fieldset> i <legend>.
    El mètode del formulari ha de ser GET.

    Exercici 18. Formularis II

    Crea la pàgina registre.html per al registre d’usuaris a la teua web.
    Crea un formulari (mètode GET) amb els següents elements, agrupats amb <fieldset> i <legend>:

    Informació personal

    • Nom (text)
    • Cognoms (text, mida 40)
    • Adreça (text, mida 60)
    • Població (text)
    • Correu electrònic (email)
    • Telèfon (tel)
    • Data de naixement (date)
    • Sexe (radio): home, dona, altres

    Contrasenya

    • Contrasenya (password)
    • Reescriure contrasenya (password)

    Informació professional

    • Nom de l’empresa (text)
    • Web de l’empresa (url, mida 60)
    • Any de fundació (number, mínim 1500, màxim 2050)
    • Sectors (checkbox, almenys 5 opcions)

    Botó enviar

    • input type="submit"

    Els camps en negreta són requerits (required).

    Afegeix els enllaços necessaris dins de <nav>.

    📦 5a Entrega

    Comprimeix la carpeta public_html en format ZIP i entrega-la a Aules amb el nom entrega5.zip

    Exercici 19 i pràctica FINAL

    En aquesta pràctica donarem els retocs finals al nostre lloc web.
    Es recomana fer-la quan tingues acabades les pràctiques anteriors.
    L’objectiu és crear un lloc web realista, amb una estructura i aparença més professionals.

    Retocs de maquetació a realitzar

    • Afegir un CSS reset o normalize a totes les pàgines.
    • Utilitzar Flexbox per a maquetar la pàgina productos.html per tal de mostrar una galeria de fotos relacionades amb els productes o projectes de la teua empresa. També pots aplicar Flexbox a qualsevol altra pàgina que ho consideres, així com altre tipus de posicionament amb position o float.

    Comprimeix la carpeta public_html en format ZIP i entrega-la a Aules amb el nom nom_empresa.zip
