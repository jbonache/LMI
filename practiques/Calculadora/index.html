    Pràctiques Events JavaScript

    1. Calculadora

    Desenvolupar una calculadora bàsica utilitzant JavaScript i esdeveniments de tipus click, fent ús de addEventListener per gestionar la interacció amb els botons. Aquesta calculadora sols farà operacions per a dos números.

    A partir d'aquets codi proporcionat, has de completar la implementació d’una calculadora funcional.

    La calculadora ha de permetre: - Introduir números fent clic als botons
    - Seleccionar una operació (+, -, *, /)
    - Mostrar l’operació en pantalla
    - Calcular el resultat en prémer el botó = , per a la operació entres els dos primers números
    - Esborrar el contingut amb el botó C

    Totes les tasques a realitzar estan especificades amb comentaris en el codi base proporcionat

    2. Calculadora per teclat

    Amplia la calculadora anterior per permetre també la interacció mitjançant el teclat, simulant clics sobre els botons. A més de funcionar amb el ratolí, la calculadora ha de respondre a les tecles del teclat com si l’usuari estiguera fent clic als botons.

    Tasques a realitzar

    1. Detectar esdeveniments de teclat
    - Utilitza addEventListener sobre document
    - L’esdeveniment serà "keydown"

    2. Identificar la tecla premuda
    - Utilitza event.key per saber quina tecla s’ha polsat

    3. Relacionar tecla → botó
    - Has de decidir quin botó correspon a cada tecla: - Números → botons numèrics
    - + - * / → operacions
    - Enter → =
    - c o Escape → C

    4. Simular el clic
    - Quan detectes una tecla, has de fer com si s’haguera fet clic al botó corresponent
    - Pots utilitzar:
    - .click() sobre l'element DOM del botó o cridar la mateixa funció que uses en els clics

    Exemple de codi quan es polsa la tecla numèrica "1"

    document.addEventListener("keydown", function(event) {
    var tecla = event.key;

    if (tecla === "1") {
        document.getElementById("b1").click();
    }
});
